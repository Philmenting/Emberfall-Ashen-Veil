Emberfall 0.49 environment geometry — original project work

All geometry in this directory is constructed by the original project source
tools/art/build_ruin_environment.py. Native placed ground continuations and
clearance rules are authored in scripts/ruin_architecture.gd. No external 3D
model, photoscan, downloaded sculpture or image-generated mesh was used.

The repository does not declare a separate public asset license for this
original geometry. This record does not grant a CC0 license or introduce a
third-party model license. Texture licensing does not change geometry ownership.
