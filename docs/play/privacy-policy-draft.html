Local game data

The game saves your character, equipment, progression, preferences, offline timestamps and current expedition on your device. The offline beta does not transmit this data to the developer or use advertising, analytics, account registration or in-app purchases. The Play build does not request Internet permission. Automatic Android backup of this app's game data is disabled.

Recovery codes

You can export a portable save recovery code. It contains your game data and is copied to the clipboard only when you request it. Keep it privately. Importing a code replaces your local game state and retains a local recovery copy. No code is sent to the developer automatically.

Optional feedback

If you choose to open the issue tracker, the game launches an external browser at GitHub. A feedback template contains the game version, platform, screen dimensions and selected game settings. Review it before posting; the game does not submit it. GitHub handles information you submit under its privacy statement. Public issues are visible to others. Avoid posting recovery codes, account keys or private information.

Retention and deletion

Local data remains until you clear the app's storage or uninstall the app. Recovery codes you copy elsewhere remain under your control. To remove feedback you submitted on GitHub, manage it through your GitHub account or contact the developer. Google Play and Android independently handle store, installation and system information under their own policies.

Changes and questions

This policy must be reviewed before enabling online features, accounts, purchases or telemetry. Contact the developer above with privacy questions.
