# Complete native avatar construction — work in progress

The fourth Sintel sample review resolved no remaining visual item. Hands and hip finish remain partial. That bounded local correction series is closed; its final source, failed builds and native evidence remain preserved in `character-reconstruction-049.md`. It is not an accepted game character.

The authorized full 3D overhaul continues with a whole adult Nyra construction using the existing verified CC0 MakeHuman/MPFB HM08 anatomy. This is the same base used by the former failed MPFB experiment. The change is preserving the complete source head, both hands and shaped source rest hierarchy, then retargeting movement to that anatomy. It is not a newly sourced higher-fidelity mesh.

The first bounded candidate uses MPFB’s native 53-joint game_engine hierarchy, including articulated fingers. Source preparation and runtime adaptation are being developed separately and must agree on an actual exported profile. The incumbent 29-joint animation library remains the legacy reference. No candidate is registered in the production body catalog yet.

Acceptance requires visible adult proportions and a coherent clothed silhouette; natural shoulders, elbows, wrists, hips, knees and ankles through native attacks; retained complete head and hands; actual finger/tool contact and measured sole support; correct imported rests, binds, weights and bounds; and an unobstructed native game-camera review. Source validation and headless checks establish technical properties, not visual quality. Supplied skin color is a legacy diffuse map; additional authored material detail must be described accurately.

Current status: the source candidate and private native runtime exist. The settled-death support correction passes the current engine fixture and narrow pixel review, while the outfit remains rejected. Neither beta readiness nor a completed whole-game graphics overhaul is established.
