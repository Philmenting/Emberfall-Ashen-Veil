# Native class evidence 055

These are seven selected, unedited original Godot runtime PNGs from a fourteen
image studio pass of the production `DungeonActor`. They inspect native model
anatomy, material/silhouette, real weapons and close hand contact. They are not a
continuous dungeon recording, an Android screenshot, or a performance benchmark.
The software desktop renderer is Mesa llvmpipe / OpenGL Compatibility; the studio
explicitly uses Dummy audio and does not claim an audible recording.

`receipt.json` binds the source files, native model and selected PNG hashes to the
actual final 398-check / 0-failure class test and the native studio run. The actual
indexed skin triangles and physical handle mesh are measured across 50 live
poses, including real hurt. Worst finger gap: 2.644 mm. Worst physical handle
penetration: 0.823 mm. The string contacts an actually weighted right-hand finger
pad at its real 2.8 mm radius. The actual arrow tip is the projectile socket, including the immediately
released hidden prop used by the real production actor. Real `basic` and
`signature` release events preserve all 65 native bone position, rotation and
scale components with zero measured change. The indexed hidden arrow tip
matches `projectile_origin()` within 0.00024 mm; its contact discontinuity is
below 0.00030 mm. Both native runs exit 0 and the five owned runtime/test inputs
remain identical to their recorded freeze hashes.

The bow arrow rest is fitted above the full native gripping fingers rather than
through their centre; the actual 3.75 mm-radius shaft clears the highest gripping
digit by 2.25 mm. Maximum visible class geometry is 33,294 triangles for Ranger
and 31,440 for Vowkeeper, including every visible weapon/armor/string/arrow.

Vowkeeper's continuous chest plate fits actual source torso triangles. The
outer bracers contain the two real continuous sleeve components without cloning
the source's disconnected straps and buckles into intersecting steel. Original
complete leather boots remain; the incorrect under-boot shin shell was removed.
The outward normals and Godot's clockwise front faces are checked on the actual
chest sheet. The underlying adult source body, native rests and source skin
weights remain unchanged.

The complete artist outfit and accepted original head/eyes/brows keep one native
65-bone hierarchy; there is no generic body mapped to the legacy 29-bone rig.
Vowkeeper uses real original rest-retargeted Sword Regular A/B/C actions; Ranger
uses a new anatomical bow draw/release phrase and original native idle/walk/death.
The entire bow phrase uses one native idle support phase, so simulation release
does not restart the idle loop or jump the lower body at contact.
No authored provider bow clip, facial blendshape animation, high-resolution armor
bake, physical Android measurement or release-quality verdict is claimed.
