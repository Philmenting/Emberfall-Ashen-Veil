# Nyra staff-grasp correction — 053

The user's observation was correct: the revision 052 staff followed the right hand, but did not pass through the finger aperture. A source sword fist was used with an incompatible shaft axis and radius. Earlier finite-socket and continuity checks could pass while the visible grasp was wrong. Those checks were insufficient grounds for the previous broad statement that the model worked correctly.

[After: actual front closeup](reference-053/grip-idle-0.4-front.png), [outer side](reference-053/grip-idle-0.4-outer.png), [back](reference-053/grip-idle-0.4-back.png), [casting contact](reference-053/grip-windup_basic-1.0-front.png). These are direct Godot renders, copied byte-for-byte, using the production Arcanist and original body materials. The diagnostic stage supplies closer cameras and studio lighting; it does not substitute a different hand/model or generated artwork.

## Change

The [production rig](../../scripts/source_avatar_rig.gd) loads [fitted native finger rotations](../../assets/models/nyra052/staff-grip053.json). Their aperture center is hand-local `(-0.03510345, 0.07532779, 0)`; the shaft axis is `(-0.03085758, 0.20407353, 0.97846911)`. The physical handle point `(0, -0.147, 0)` in the prop is attached to this aperture, rather than placing the prop origin at a generic hand offset. The ornament is rolled toward the character's front without changing its grasp axis.

A native two-link support-arm solve presents the hand aperture to an upright staff, preserving original upper-arm and forearm lengths. Finger curling is adjusted individually from the native source rest/sword pose. The left-hand casting clip and game-controlled projectile release retain their existing behavior. The authored body GLB, original skin weights, rest hierarchy, UVs and face are unchanged: body SHA-256 `d489ad6a55510a5bd36f0215fcb3be1a596cab6094500f19476e3fc172e7e4e1`.

The [portable staff builder](../../tools/art/fit_nyra053_staff.py) retains the five existing Emberfall weapon parts/materials, removes four raised leather wraps (954 triangles), and introduces real section boundaries before tapering the handle. This produces an actual 18 mm runtime radius across the grasp, rather than just assuming that radius in a test. Section-cut normals are normalized before export. The ornament and gold rings remain. The source prop deliberately has plain materials and no UV0; this is a geometric grasp correction, not a new texture bake.

Final staff SHA-256: `98bd5832256f9a2fdbb68198d1dbf0d2db0b87c9c4d9d28b136cdfe54db0f11c`. A separate rebuild reproduced these bytes. An [independent CPU mesh audit](reference-053/staff-mesh-audit.json) checks all 2,664 used triangles: finite attributes, no degenerates, winding consistent with normals, and unit normals within `1e-6`.

## Verification

The [actual hand-surface smoke test](../../tests/source_avatar_grip_smoke.gd) passed **296 checks across 40 direct and real transition poses**, zero failures, actual process exit 0 and unchanged inputs: [receipt](reference-053/grip-test-receipt.json), [complete log](reference-053/grip-test-process.log). Godot 4.7.2 was used; logs were scanned for script, parse and runtime errors as well as checking exit status.

This test reconstructs every referenced source arm vertex using all four original skin influences. Indexed triangles clipped to the grasp span measure shaft penetration, finger contact and opposed thumb/finger directions. All arm triangles contribute to clearance, including mixed-bind triangles. A separate check clips the actual rendered handle geometry and verifies a radius between 17 and 18.5 mm, preventing raised wraps or a thicker mesh from escaping the assumed cylinder check. Maximum measured penetration is **0.472 mm** (limit 1 mm); maximum measured finger gap is **2.465 mm** (limit 3 mm). The grip wraps with the fingers and thumb; the measured palm gap is approximately 9.8 mm, so tight full-palm contact is not claimed.

The 40 poses cover idle, walk, basic/heavy casting and recovery; actual 60 Hz walk/stop blends; basic/signature windup, real early release and recovery transitions. At early release the actual grip and tip remain within the existing 25 mm continuity limit. The staff stays upright in the living support hand. This is sampled geometric verification, not an assertion that every rendered animation frame is artistically perfect.

Four existing suites also passed without script/runtime errors: source avatar 39 checks, character 3D 164, world framing 900, visuals 73. [Summary](reference-053/regressions-summary.json) and individual receipts/logs are in this directory. Those regressions used the staff before the final normal-only cleanup. The independent audit establishes byte-identical positions/indices/materials across that cleanup; the 296-check grip test and final stills were rerun with the final asset.
