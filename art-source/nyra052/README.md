# Editable Nyra conversion

`nyra052-editable-conversion.blend` is a packed Blender 5.1 import of the actual CC0 native65 runtime GLB, with all eight source meshes and all 65 bones. This is an editable conversion, **not** Quaternius' original paid artist Blender source or high-poly/bake source. Source, license and reconstruction: [runtime source record](../../assets/models/nyra052/README.md).

The conversion includes Blender's hidden bone-display Icosphere helper. It is excluded from the eight-mesh avatar inventory. Blender may represent bone axes differently; verified game export uses the original native65 GLB/assembly pipeline. Runtime staff is attached separately and is not part of this Blender conversion.

`.gdignore` keeps the authoring file out of automatic Blender imports and game exports.
